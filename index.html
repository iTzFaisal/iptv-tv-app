📺 IPTV Web Player

Enter your Xtream Codes credentials once. They are stored only in this browser (localStorage) and are only ever sent to your provider's panel and your own Cloudflare Worker gateway.

Where do I get a Worker URL?

Playback needs a tiny stream gateway because provider streams are http-only. Deploy the single file in worker/cloudflare-worker.js to Cloudflare Workers (free) — see the repo README for the 2-minute guide. Running locally? Use npx wrangler dev worker/cloudflare-worker.js and enter http://127.0.0.1:8787.

Heads-up: the provider's movie servers currently return errors (all movie links 404 upstream as of 2026-10-14). You can browse the catalog, but playback may fail until the provider fixes it — the player will show a friendly notice if so.

Export

Links are generated in your browser from the cached catalog — no giant playlist download from the provider needed. Files are UTF-8 and keep Arabic names. The panel-format URLs contain your username and password — keep the files private.

playlist-all.m3u

Everything: live channels (Xtream format) + movies + cached series episodes.

live-hls.m3u

Live channels as modern .m3u8 links for VLC and friends.

playlist-series.m3u

All series episodes. First run fetches episode ids from the panel (a few minutes, cached afterwards).

catalog.csv

Spreadsheet of id, type, name, category, added, rating, poster, container.

catalog.json

Same data as JSON for scripts.
