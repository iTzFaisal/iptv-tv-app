IPTV playback check

Manual / Playwright harness. Serve this folder over http (e.g. python3 -m http.server 8080 from the repo root) and open http://localhost:8080/test/playback-check.html?user=…&pass=…&channel=526337&episode=900353. Leave worker empty to test the raw http panel host (local dev); fill it in to test the Cloudflare Worker gateway. Results land in window.__RESULTS.
